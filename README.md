# PMIC — демо MVP

AI-платформа прогнозного управления стоимостью, сроками и рисками строительных проектов.
Интерактивный прототип личного кабинета: статический сайт без сборки, работает на GitHub Pages.

## Быстрый старт

```bash
# локально (нужен любой статический сервер — ES-модули не работают через file://)
python3 -m http.server 8080
# открыть http://localhost:8080
```

Вход: кнопка «Войти в демо без регистрации», ссылка `…/#/demo` или любой email и пароль.

Ссылка для клиента: `https://<логин>.github.io/<репозиторий>/#/demo` — сразу открывает кабинет с приветствием и гидом по демо.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое папки целиком (вместе с `.nojekyll`).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Все пути относительные, маршрутизация через `#/…`, поэтому сайт работает и в подпапке репозитория.

## Живое демо: что можно «пощупать»

- **Свой проект за минуту:** шаблоны «Жилой дом (МКД)», «Спортивный объект», «ИЖС», «Бизнес-центр», «С нуля» — этапы, сроки и бюджет раскладываются автоматически.
- **Импорт графика из Excel/CSV** (.xlsx, .xls, .csv): колонки «Название», «Начало», «Окончание», «Бюджет», «% выполнения»; вложенность по коду 1 / 1.1 / 1.1.1, колонке «Уровень» или отступам. Шаблон для заполнения скачивается из окна импорта.
- **Редактирование структуры:** добавить/удалить этап и подэтап, изменить сроки, бюджет, процент; сдвиг этапов перетаскиванием на диаграмме Ганта, изменение срока — за правый край полосы.
- **Сквозной пересчёт:** закрытие задачи → прогресс работы → этапа → проекта → главная, мониторинг, финансы, AI-прогноз.
- **AI-прогноз проекта:** метод освоенного объёма и «заработанного графика» (SPI, CPI), прогноз даты окончания и итоговой стоимости, индекс риска с разложением по факторам, вероятность срыва срока, S-кривая «план/факт/прогноз», сценарии «что если» (задержка оплаты, рост цен, численность), рекомендации с проверкой сценария.
- **Выгрузка в Excel:** структура, финансы, прогноз, отчёты. PDF — через печать.
- **Гид по демо** (7 шагов с отметками), **сброс демо-данных**, **форма «Обсудить внедрение»**.

## Настройки (`js/config.js`)

| Параметр | Что делает |
|---|---|
| `supabaseUrl`, `supabaseKey` | Совместный режим: все участники по одной ссылке работают с общими данными |
| `workspace` | Имя общего пространства по умолчанию; можно задать в ссылке: `…/?ws=company#/demo` |
| `metrikaId` | Номер счётчика Яндекс Метрики: просмотры, вебвизор и цели (`project_created`, `stage_edited`, `gantt_drag`, `task_closed`, `whatif_used`, `import_done`, `excel_export`, `feedback_sent`) |
| `feedbackUrl` | Адрес обработчика формы «Обсудить внедрение» (POST JSON, например Formspree). Пусто — откроется письмо на `feedbackEmail` |

### Совместный режим (Supabase)

1. Создайте проект на supabase.com (бесплатного тарифа достаточно).
2. В SQL Editor выполните:

```sql
create table if not exists pmic_workspaces (
  id text primary key,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table pmic_workspaces enable row level security;
create policy "demo read"   on pmic_workspaces for select using (true);
create policy "demo insert" on pmic_workspaces for insert with check (true);
create policy "demo update" on pmic_workspaces for update using (true);
```

3. Project Settings → API: скопируйте Project URL и anon public key в `js/config.js`.
4. Для каждой компании давайте свою ссылку: `…/?ws=ooo-romashka#/demo` — у каждой будет отдельное пространство.

Синхронизация: изменения отправляются через ~0,6 с, изменения коллег подтягиваются раз в 8 секунд. Политики выше открыты для демо — для боевого использования нужна авторизация.

## Что реализовано

| Раздел | Функциональность |
|---|---|
| Вход | Форма, показ пароля, «Запомнить данные», восстановление пароля, выход |
| Личный кабинет | KPI-карточки с диаграммами, прогресс избранного проекта и риски, задачи, согласование документов |
| Глобальный поиск | Проекты, документы, задачи, сотрудники; навигация клавиатурой, `Ctrl+K` |
| Профиль и настройки | Профиль, учётная запись, темы оформления: светлая, тёмная, голубая и свой акцентный цвет |
| Проекты | Все/мои, строительство и эксплуатация, плитка/список, поиск, сортировка, фильтр, создание и удаление проекта |
| Карточка проекта | 9 вкладок: Обзор, Структура, Диаграмма, BIM-модель, Панель мониторинга, Файлы, Прямой эфир, Счета, Госуслуги |
| Структура (WBS) | Дерево этапов, поля, фильтр, сортировка, экспорт CSV, карточка этапа с комментариями |
| PMIC AI | «Прогноз затрат»: расчёт трудозатрат, численности, стоимости и доверительного интервала, выгрузка CSV и печать |
| Диаграмма Ганта | Масштаб месяц/квартал/полугодие/год, сворачивание таблицы, полноэкранный режим, печать |
| BIM-модель | 3D-модель стадиона (three.js): слои этажей, подвал/фундамент, секции, вращение, комментарии-метки, отчёт о коллизиях |
| Мониторинг | Плитки задач, кольцевая диаграмма, активность, события; списки задач с поиском и пагинацией |
| Файлы | Группы документов, загрузка (с компьютера, drag&drop, облака — имитация), права доступа, согласование, предпросмотр, комментарии |
| Прямой эфир | Камеры объекта, увеличенный просмотр, снимок |
| Счета | Онлайн-оплата: выбор банка → демо-шлюз → статус «Оплачено» |
| Госуслуги | Каталог услуг, инструкция, подача заявления (демо-шаг) |
| Задачи (MVP 2.0) | Все/мои, плитка/список, поиск, сортировка по колонкам, фильтр, новая задача, карточка задачи: статус, принять/на доработку/переоткрыть, вложения, комментарии, решение, история |
| Сотрудники | Плитка/список, поиск, сортировка, фильтр по отделу, карточка сотрудника (редактирование, проекты, задачи, удаление учётной записи) |
| Приглашение | Анкета сотрудника, проекты, группы прав и детальная настройка прав (управление проектами, таск-менеджмент, учётные записи) |
| Финансы | Бюджет проекта, транзакции, панель управления (индикаторы, план/факт, структура расходов), счета |
| Отчёты | Шаблоны и автоматические отчёты, создание, предпросмотр, печать/PDF, CSV |
| Документы | Согласованные / несогласованные / ожидание, действия над документами |

Адаптивность: десктоп (≥1240 px), ноутбук/планшет (900–1240 px, компактное меню), телефон и планшет (<900 px: выдвижное меню, нижняя панель, таблицы-карточки, модальные окна-шторки).

## Важно

- Все данные демонстрационные и хранятся только в браузере (localStorage). Сброс: очистить данные сайта.
- Оплата и Госуслуги — имитация шага интеграции, реальные платежи и заявления не отправляются.
- Даты демо-данных автоматически сдвигаются к сегодняшнему дню — демо не «стареет».
- Подключение бэкенда: `js/sync.js` (Supabase) или замена `js/db.js` на вызовы API.
